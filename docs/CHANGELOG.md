## [1.0.0] - 2026-08-17

### Added

- Initial backend docs hub structure (`README.md`, `START_HERE.md`, `AGENT_GUIDE.md`, `PROGRESS.md`, `versioning/CONVENTIONS.md`).
- Integrated `architecture/architecture-design.md` for NestJS backend conventions, DTO boundaries, interceptors, and security policy.
- Added per-module progress trackers under `features/<module>/progress.md` for all 12 NestJS backend feature modules (`admin`, `analytics`, `auth`, `catalog`, `community`, `dogs`, `media`, `moderation`, `payment`, `pets`, `predictions`, `users`).
- Added master backend progress dashboard in `PROGRESS.md`.
